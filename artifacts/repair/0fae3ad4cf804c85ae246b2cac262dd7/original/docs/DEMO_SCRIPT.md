# TestForge AI v1.4.0 demo

1. Start the backend and frontend in separate terminals using the root README instructions.
2. Submit a public website you are authorized to test. Use Quick, Standard, or Deep.
3. Open the completed run and show the page coverage panel: pages discovered, pages visited, forms observed, crawl limit, and screenshots for each visited page.
4. Open a page screenshot and compare it with the URL shown in the coverage row. Do not call a crawl complete if the page limit was reached.
5. Open Evidence & findings. Show each finding's page-specific evidence and distinguish same-origin defects from third-party/access-policy information.
6. For a controlled CRUD demo, use a staging application and a dedicated disposable record. Configure the workflow JSON for create, read, update, delete, and assertions. Show the screenshot and pass/fail status for each step.
7. Export the JSON report.
8. If demonstrating Vultr isolation, show the actual Vultr VM, guest creation, resource limits, network policy, execution, and teardown. Local Windows screenshots are not proof of sandbox containment.
